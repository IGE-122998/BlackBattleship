#📋 Product Backlog – Jogo Batalha Naval Online (PaperGames)
##🧩 User Stories
🔐 Conta e Autenticação
Como utilizador, quero criar uma conta para poder jogar e guardar o meu progresso.
Como utilizador, quero fazer login para aceder à minha conta.
Como utilizador, quero fazer logout para sair da minha conta em segurança.
Como utilizador, quero recuperar a minha password caso me esqueça dela.
🎮 Jogabilidade (Batalha Naval)
Como jogador, quero iniciar um jogo de batalha naval para poder jogar online.
Como jogador, quero jogar contra outro jogador para competir em tempo real.
Como jogador, quero jogar contra um bot para praticar.
Como jogador, quero posicionar os meus navios no tabuleiro para começar o jogo.
Como jogador, quero atacar posições no tabuleiro adversário para tentar afundar navios.
Como jogador, quero receber feedback (acertou/falhou) após cada jogada.
Como jogador, quero ver quando o jogo termina para saber se ganhei ou perdi.
👥 Multiplayer e Convites
Como utilizador, quero gerar um link de convite para jogar com amigos.
Como utilizador, quero entrar num jogo através de um link recebido.
Como utilizador, quero partilhar jogos com outros jogadores.
🏆 Torneios
Como utilizador, quero criar um torneio para competir com vários jogadores.
Como utilizador, quero definir regras do torneio (jogo, participantes, etc.).
Como utilizador, quero consultar os meus torneios criados.
Como utilizador, quero participar em torneios organizados por outros jogadores.
🛒 Loja e Subscrições
Como utilizador, quero consultar a loja para ver produtos disponíveis.
Como utilizador, quero comprar subscrições (ex: plano Plus) para desbloquear funcionalidades.
Como utilizador, quero visualizar preços e planos disponíveis.
Como utilizador, quero adquirir funcionalidades premium (Games-as-a-Service).
📊 Perfil e Progresso
Como utilizador, quero visualizar o meu perfil para acompanhar estatísticas.
Como utilizador, quero ver o histórico de jogos realizados.
Como utilizador, quero acompanhar o meu ranking.
📚 Ajuda e Documentação
Como utilizador, quero consultar guias dos jogos para aprender a jogar.
Como utilizador, quero aceder à documentação técnica (API/devs).
📢 Comunicação e Comunidade
Como utilizador, quero aceder às redes sociais para acompanhar novidades.
Como utilizador, quero entrar no Discord para comunicar com a comunidade.
Como utilizador, quero ler o blog para saber atualizações do jogo.
⚙️ Configurações e Informações Legais
Como utilizador, quero consultar os termos e condições para conhecer as regras da plataforma.
Como utilizador, quero consultar a política de privacidade para saber como os meus dados são usados.
Como utilizador, quero contactar suporte para resolver problemas.
📱 Aplicação Mobile
Como utilizador, quero instalar a app mobile para jogar no telemóvel.
Como utilizador, quero avaliar a aplicação na App Store ou Google Play.
