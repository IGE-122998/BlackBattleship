# 📋 Product Backlog – Jogo Batalha Naval Online (PaperGames)
  
## 🧩 User Stories

### 🔐 Conta e Autenticação
1. Como utilizador, quero criar uma conta para poder jogar e guardar o meu progresso.
2. Como utilizador, quero fazer login para aceder à minha conta.
3. Como utilizador, quero fazer logout para sair da minha conta em segurança.
4. Como utilizador, quero recuperar a minha password caso me esqueça dela.

---

### 🎮 Jogabilidade (Batalha Naval)
5. Como jogador, quero iniciar um jogo de batalha naval para poder jogar online.
6. Como jogador, quero jogar contra outro jogador para competir em tempo real.
7. Como jogador, quero jogar contra um bot para praticar.
8. Como jogador, quero posicionar os meus navios no tabuleiro para começar o jogo.
9. Como jogador, quero atacar posições no tabuleiro adversário para tentar afundar navios.
10. Como jogador, quero receber feedback (acertou/falhou) após cada jogada.
11. Como jogador, quero ver quando o jogo termina para saber se ganhei ou perdi.

---

### 👥 Multiplayer e Convites
12. Como utilizador, quero gerar um link de convite para jogar com amigos.
13. Como utilizador, quero entrar num jogo através de um link recebido.
14. Como utilizador, quero partilhar jogos com outros jogadores.

---

### 🏆 Torneios
15. Como utilizador, quero criar um torneio para competir com vários jogadores.
16. Como utilizador, quero definir regras do torneio (jogo, participantes, etc.).
17. Como utilizador, quero consultar os meus torneios criados.
18. Como utilizador, quero participar em torneios organizados por outros jogadores.

---

### 🛒 Loja e Subscrições
19. Como utilizador, quero consultar a loja para ver produtos disponíveis.
20. Como utilizador, quero comprar subscrições (ex: plano Plus) para desbloquear funcionalidades.
21. Como utilizador, quero visualizar preços e planos disponíveis.
22. Como utilizador, quero adquirir funcionalidades premium (Games-as-a-Service).

---

### 📊 Perfil e Progresso
23. Como utilizador, quero visualizar o meu perfil para acompanhar estatísticas.
24. Como utilizador, quero ver o histórico de jogos realizados.
25. Como utilizador, quero acompanhar o meu ranking.

---

### 📚 Ajuda e Documentação
26. Como utilizador, quero consultar guias dos jogos para aprender a jogar.
27. Como utilizador, quero aceder à documentação técnica (API/devs).

---

### 📢 Comunicação e Comunidade
28. Como utilizador, quero aceder às redes sociais para acompanhar novidades.
29. Como utilizador, quero entrar no Discord para comunicar com a comunidade.
30. Como utilizador, quero ler o blog para saber atualizações do jogo.

---

### ⚙️ Configurações e Informações Legais
31. Como utilizador, quero consultar os termos e condições para conhecer as regras da plataforma.
32. Como utilizador, quero consultar a política de privacidade para saber como os meus dados são usados.
33. Como utilizador, quero contactar suporte para resolver problemas.

---

### 📱 Aplicação Mobile
34. Como utilizador, quero instalar a app mobile para jogar no telemóvel.
35. Como utilizador, quero avaliar a aplicação na App Store ou Google Play.
